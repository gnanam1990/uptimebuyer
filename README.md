# UptimeBuyer

From refrigeration failure to verified recovery, with bounded autonomous spend.

UptimeBuyer turns a commercial-refrigeration fault into an evidence-bound recovery plan, lets deterministic policy (not a model) decide what is compatible and safe, spends only inside an explicitly approved Kite session through an exclusive payment broker, and closes the incident only after independent telemetry plus CMMS/operator evidence proves recovery.

> Status: under construction. The specification lives in [`docs/spec/`](docs/spec/START-HERE.md); its invariants in [`docs/spec/CORE-CONTRACT.md`](docs/spec/CORE-CONTRACT.md) are binding. Nothing in this repository claims real provider fulfillment, real Kite payment, physical recovery or production readiness until the evidence in `evidence/` says so.
